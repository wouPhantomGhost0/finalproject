CraveMatch — Group Dining Preference Matcher

CraveMatch helps groups quickly decide where to eat by combining budget limits, location radius, dietary restrictions, and swipe-based restaurant voting into an AI-assisted consensus recommendation.

Features
- **User Authentication:** Log in or sign up to create and join group dining sessions.
- **Group Session Lobby:** Hosts can start a room with custom budget, distance radius, and dietary filters, generating a shareable room code for friends to join
- **Interactive Swipe Deck:** Participants swipe right or left on nearby restaurants filtered to fit the group's constraints.
- **Consensus & Insights Engine:** Calculates group dietary overlap and scores restaurants to surface the top 3 optimal matches with an AI-generated explanation.

 Tech Stack
- **Frontend:** React, Vite, Lucide React Icons
- **Backend:** Node.js, Express
- **Database:** MongoDB / Mongoose
